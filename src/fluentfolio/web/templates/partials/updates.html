To update, install the new version over this one:

  1. Open the releases page and download the newest Source code zip.
  2. Extract the zip to a folder of your choice.
  3. Quit Fluentfolio, then double-click Install.cmd in that folder (on Linux, run install.sh). Your recordings, results and settings are kept.

This asks GitHub for the newest version number. Nothing about you or your recordings is sent.
