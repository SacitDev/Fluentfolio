# Fluentfolio documentation

Start at the top and go down as far as you need. The pages for using Fluentfolio are written for learners, not programmers; the last group is for people who want to change the code. The app has the short version of the first three pages on its Help page.

```mermaid
flowchart TD
    N["New to Fluentfolio?"] --> U["User guide<br/>install and first analysis"]
    U --> R["Recording guide<br/>the clearest results"]
    R --> A["Use with AI<br/>a chat or an AI agent"]
    Q["Curious how it works?"] --> H["How it works<br/>steps and diagrams"]
    H --> L["Limitations and Accuracy"]
    P["Something went wrong?"] --> T["Troubleshooting<br/>every error code"]
    D["Want to change the code?"] --> AR["Architecture<br/>the parts and why"]
    AR --> DV["Development<br/>tests and new features"]
```

The links are in the tables below.
